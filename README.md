## Featured Work

### 🤖 Multi-Agent LLM Systems
Designing agent frameworks where role-specialized models independently research, debate, and produce weighted consensus votes. Focus on calibrated confidence, anti-herd-voting reflection prompts, and structured JSON outputs alongside streaming prose.

### 📈 Market Data & Quantitative Pipelines
End-to-end ETL for multi-ticker financial data, with bronze/silver/gold/AI-layer schemas, technical feature engineering (returns, SMA/EMA, Bollinger, volatility), and scheduled LangChain agents for news synthesis. Containerized on AWS, orchestrated by Airflow.

### 🏀 Sports Analytics & Predictive Modeling
XGBoost regression on 1,500+ player-seasons to model salary efficiency. Hyperparameter tuning with k-fold CV, residual analysis to surface market mispricings, and feature engineering across advanced metrics (OBPM, DBPM, VORP).

### 🏥 Healthcare Data Engineering
Longitudinal patient-data infrastructure for outcomes tracking, with matched-cohort comparison engines, pharmacovigilance flags, and granular consent propagation for downstream ML.
